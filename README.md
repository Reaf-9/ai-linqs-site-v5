# AI Linqs コーポレートサイト v5

SPEC-v5.md を優先し、SPEC.md の基本デザインルールを引き継いだ6ページの静的サイトです。HTML・CSS・JavaScriptを直接編集します。ビルドや生成処理は不要です。既存の参照用スクリプトは実行していません。

## v5の変更点

- 全ページのセクション見出しと下層ページの帯を、日本語ラベル・青い装飾英字・必要に応じた既存日本語見出しに統一。英字は Inter 300、64〜120px、`aria-hidden="true"`。日本語の見出しは読み上げ可能です。
- セクションと帯の上下余白を160px、767px以下では96pxに変更。カードは12px、LINE枠・フッター等の大枠は24px。標準ボタンは56pxの白い輪と1.5px線のSVG矢印、右に14pxのラベルを配置。
- LINE CTAの緑の錠剤型を保持。ホバー・押下時の暗色レイヤーは指定パレット内の文字色に統一。
- トップのサービス紹介をAI研修中心の左右配置に変更。期間札と `service.html#front` へのリンク、3つの次サービスへのテキストリンクを配置。
- サービスページを、研修 → 次の一手3件 → 選び方 → その他 → 契約フロー → FAQ → 相談案内に再構成。
- 研修の4段階図をHTMLとCSSで作成。既存の研修・AI社員詳細は全文を保持し、ネイティブの `<details class="more">` に収納。アプリ・AI顧問には未指定の詳細文や空の開閉ボタンを追加していません。
- 比較表を指定の5行の対応図に置換。士業AIの既存説明・ボタンはその他サービスに統合。トップの契約フロー図と4工程の見出し・本文・挿絵をサービスページにも再掲。
- キャッチ、事例の課題・成果、会社情報表を保持。並列のお悩み・理由カードの見出しは `<br>` で2行に固定し、本文は `text-wrap: pretty`。
- 白からの0.4秒フェード、冒頭見出しの16px・0.6秒の登場、挿絵の1.04→1・1.2秒の縮小、通常要素の0.6秒フェードを設定。ヒーローは既存ポスターを表示し、自動動画再生と点滅を停止。`prefers-reduced-motion` ではアニメーション・トランジションを無効化し、設定変更にも追従。
- 既存のイラスト、QR、サイン、faviconを使用。画像の生成・追加・変更なし。

## 色・角丸

CSSのHEX色は `#FFFFFF`、`#EDF1F9`、`#327AFA`、`#0F0F11`、`#616267`、`#9798A1`、`#06C755` の7色です。影・グラデーションはありません。透過は指定色の要素のopacityで表現しています。

角丸は4px（期間札）、12px（カード・写真）、24px（大枠）、9999px（丸・錠剤型）。角丸を付けない既存要素には0を使用。

## 機能とリンク

- LINE URL：`https://lin.ee/XFEkgJS`。`data-line-cta` のリンクをJSで差し替え、新しいタブで開きます。JS無効時はお問い合わせページとQRを利用できます。
- 現在ページのナビ表示、Escape・外側クリック・リンク選択で閉じるモバイルメニュー、モバイル固定LINE CTAを維持。
- 詳細とFAQはJS無効でも開閉可能。詳細IDへの直接リンク時はJSで該当のdetailsを開きます。
- サービスのリンク先：`#front`、`#aistaff`、`#app`、`#advisor`。全体の区分：`#next`、`#choose`、`#others`、`#process`、`#faq`、`#service-consult`。
- 全ページの `noindex,nofollow`、favicon、ローカル／github.ioのみの「テスト版 v5」を維持。

## 検査と描画レビュー

静的検査で6ページのHTMLの入れ子、重複ID、ローカル参照ファイル、内部アンカー、装飾英字の `aria-hidden` を確認しました。サービスのセクション順、比較表の撤去、使用色と角丸、影・グラデーション不使用も確認済みです。`node --check js/main.js` は通過しました。

変更前のデータとの照合で、既存catchの文字列、事例の課題・成果、会社情報表が一致すること、研修・AI社員詳細の既存HTML全文が移動後も保持されていることを確認しました。

ブラウザでの描画確認は依頼どおり実施していません。390／768／1280／1440pxを想定し、狭い幅の左右配置とリンク一覧を縦に切り替え、グリッドに `minmax(0,1fr)` を使用しています。実際の横スクロール・文字の収まり・動作の描画レビューはレビュー担当者が行います。

git操作・ファイル削除・このフォルダ外への書き込みは行っていません。公開前には既存の `[要確認]`、会社情報、掲載許諾、料金、noindexとテスト印を確認してください。
